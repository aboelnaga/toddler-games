# Tap-to-Discover Zoo (Slice 5) Implementation Plan

> Medium-depth plan in the same shape as Slices 3 and 4. Each task lists files, the key code sketch, and the verification commands. Where code is abbreviated, follow the existing patterns from `lib/features/games/finger_paint/`, `bubble_pop/`, and `shape_sorter/`.

**Goal:** Build the Tap-to-Discover Zoo mini-game end-to-end. A wide horizontal-scroll watercolor meadow with 7 animals (cow, bird, cat, dog, duck, elephant, sheep) scattered at natural positions. Tap any animal → it plays a brief bounce/wiggle animation + an SFX (animal sound) + a spoken voice clip with its name in the active locale (ar-EG or en). No goal, no end, no fail state.

**Architecture:**
- `lib/features/games/zoo/` — self-contained feature folder, mirroring `finger_paint/` / `bubble_pop/` / `shape_sorter/` shape.
- `models/zoo_animal.dart` — `enum ZooAnimal { cow, bird, cat, dog, duck, elephant, sheep }` plus a const map of per-animal config (asset path, scene-space position, scale).
- `animal_view.dart` — single animal widget. Wraps an `Image.asset` in a `GestureDetector` + an `AnimatedScale`/`AnimatedRotation` couple that runs a brief bounce on tap.
- `zoo_screen.dart` — root screen. `Scaffold` → `SafeArea` → `SingleChildScrollView(scrollDirection: Axis.horizontal)` → `Stack` containing the backdrop image + all 7 `AnimalView`s positioned via `Positioned`. Home-button overlay top-left.
- *(No notifier needed.)* State is local to each `AnimalView` (currently animating? bool). Cross-animal coordination is unnecessary — the spec is explicit that there's no goal or progression, so we don't need a shared state model.

**Tech stack:** Flutter stable / Dart 3.x · Riverpod 3 (only to read `audioServiceProvider` + `settingsProvider`) · go_router 17 · `Image.asset` for sprites & backdrop · `AnimatedScale` + `AnimationController` for the per-tap bounce.

## Game design constants (locked in this slice)

- Backdrop image dimensions: 3584×1184 source → optimized to **2048×676** for bundling (preserves the 3.03:1 aspect, halves byte size).
- Sprite source dimensions: 2048×2048 → optimized to **512×512** with alpha channel (after cream chroma-key + watermark crop).
- On-screen layout: the backdrop fills the screen height (`fit: BoxFit.fitHeight`); horizontal scroll reveals the rest.
- Animal positions are stored as **fractions of the backdrop's logical size** so they scale correctly regardless of viewport. Stored in `ZooAnimalConfig.position` as a `Rect.fromCenter(...)`.
- Bounce animation: scale up to 1.15× over 120ms, back to 1.0× over 180ms, with a tiny 5° rotation wobble. Total ~300ms.
- Tap target: the visible sprite bounds. Generous because each animal is rendered at ~140dp.

**Animal layout map** (fractions of backdrop, locked in `zoo_animal.dart`):

| Animal   | x (fraction of width) | y (fraction of height) | scale |
|----------|---:|---:|---:|
| duck     | 0.16 | 0.78 | 0.85 |  ← beside the pond
| cow      | 0.32 | 0.72 | 1.00 |
| sheep    | 0.45 | 0.70 | 0.95 |
| bird     | 0.55 | 0.55 | 0.75 |  ← perched higher
| cat      | 0.66 | 0.74 | 0.90 |
| dog      | 0.78 | 0.72 | 0.95 |
| elephant | 0.90 | 0.68 | 1.15 |  ← biggest of the lineup

The numbers may need a one-pass tweak after first render — they're calibrated against the scene's painted features (pond at ~15-20% x, trees at the edges, etc.) but real-device verification matters.

## Task 1: Asset optimization script

**Files:** `scripts/optimize_art.py` (create), `assets/images/games/zoo/*.png` (generated).

The masters in `art/style-bible/` are 2-5MB PNGs unsuitable for bundling. We need a Python script that produces optimized derivatives.

- [ ] **Step 1.** Create `scripts/optimize_art.py`:

```python
#!/usr/bin/env python3
"""Optimize style-bible masters into bundle-ready assets.

Usage:
  python3 scripts/optimize_art.py            # process all
  python3 scripts/optimize_art.py --asset animal_cow

Operations per sprite (cream background → transparent):
  1. Crop a 5% border off all sides (removes Gemini sparkle watermark).
  2. Chroma-key the cream #fff5e6 background to alpha=0 with a tolerance.
  3. Resize to 512x512, preserving aspect via padded transparent canvas.
  4. Save to assets/images/games/<game>/<name>.png.

Operations per scene (watercolor backdrop, no alpha key):
  1. Crop a 3% border off all sides (Gemini sparkle).
  2. Resize to 2048 wide (preserve aspect).
  3. Save to assets/images/games/<game>/<name>.png.

Requires: pip install pillow
"""

import argparse, sys
from pathlib import Path
from PIL import Image

REPO = Path(__file__).resolve().parent.parent
STYLE_BIBLE = REPO / "art" / "style-bible"

# (source filename, bundle path, kind)
ASSETS = [
    # Zoo sprites
    ("animal_cow.png", "assets/images/games/zoo/animal_cow.png", "sprite"),
    ("animal_bird.png", "assets/images/games/zoo/animal_bird.png", "sprite"),
    ("animal_cat.png", "assets/images/games/zoo/animal_cat.png", "sprite"),
    ("animal_dog.png", "assets/images/games/zoo/animal_dog.png", "sprite"),
    ("animal_duck.png", "assets/images/games/zoo/animal_duck.png", "sprite"),
    ("animal_elephant.png", "assets/images/games/zoo/animal_elephant.png", "sprite"),
    ("animal_sheep.png", "assets/images/games/zoo/animal_sheep.png", "sprite"),
    # Zoo scene
    ("scene_zoo.png", "assets/images/games/zoo/scene_zoo.png", "scene"),
    # (Future: Slice 6 — vehicle-car, scene_drive)
]

SPRITE_SIZE = 512
SCENE_WIDTH = 2048
CREAM = (255, 245, 230)  # #fff5e6
CREAM_TOLERANCE = 18     # color distance threshold for alpha keying

def crop_border(img: Image.Image, percent: float) -> Image.Image:
    w, h = img.size
    dx, dy = int(w * percent), int(h * percent)
    return img.crop((dx, dy, w - dx, h - dy))

def cream_to_alpha(img: Image.Image) -> Image.Image:
    img = img.convert("RGBA")
    px = img.load()
    w, h = img.size
    cr, cg, cb = CREAM
    for y in range(h):
        for x in range(w):
            r, g, b, a = px[x, y]
            d = abs(r - cr) + abs(g - cg) + abs(b - cb)
            if d < CREAM_TOLERANCE:
                px[x, y] = (r, g, b, 0)
    return img

def fit_into_square(img: Image.Image, size: int) -> Image.Image:
    img.thumbnail((size, size), Image.LANCZOS)
    canvas = Image.new("RGBA", (size, size), (0, 0, 0, 0))
    ox = (size - img.width) // 2
    oy = (size - img.height) // 2
    canvas.paste(img, (ox, oy), img)
    return canvas

def process_sprite(src: Path, dst: Path):
    img = Image.open(src)
    img = crop_border(img, 0.05)
    img = cream_to_alpha(img)
    img = fit_into_square(img, SPRITE_SIZE)
    dst.parent.mkdir(parents=True, exist_ok=True)
    img.save(dst, "PNG", optimize=True)
    print(f"  sprite {src.name} -> {dst.relative_to(REPO)}  ({img.size})")

def process_scene(src: Path, dst: Path):
    img = Image.open(src).convert("RGB")
    img = crop_border(img, 0.03)
    new_w = SCENE_WIDTH
    new_h = int(img.height * (new_w / img.width))
    img = img.resize((new_w, new_h), Image.LANCZOS)
    dst.parent.mkdir(parents=True, exist_ok=True)
    img.save(dst, "PNG", optimize=True)
    print(f"  scene  {src.name} -> {dst.relative_to(REPO)}  ({img.size})")

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--asset", help="process only this source filename")
    args = parser.parse_args()

    for src_name, bundle_path, kind in ASSETS:
        if args.asset and args.asset not in src_name:
            continue
        src = STYLE_BIBLE / src_name
        dst = REPO / bundle_path
        if not src.exists():
            print(f"  skip {src_name} (master missing)", file=sys.stderr)
            continue
        if kind == "sprite":
            process_sprite(src, dst)
        else:
            process_scene(src, dst)

if __name__ == "__main__":
    main()
```

## Task 5: AnimalView widget

**Files:** `lib/features/games/zoo/animal_view.dart` (create).

Stateful widget. On tap:
1. Run a `Tween<double>(begin: 1.0, end: 1.15)` scale animation, ~120ms forward + 180ms reverse via `AnimationController`.
2. Fire `audio.playSfx(config.sfxKey)` immediately.
3. Fire `audio.playVoice(config.voiceKey, locale)` after the SFX (~150ms delay so the sound + name don't overlap).

The widget is positioned absolutely by its parent (`Positioned(left: x, top: y, child: AnimalView(...))`). It does NOT compute its own position from fractions — that's the parent's job, so the widget stays decoupled from the scene's dimensions.

```dart
class AnimalView extends ConsumerStatefulWidget {
  const AnimalView({required this.config, required this.tileSize, super.key});
  final ZooAnimalConfig config;
  final double tileSize; // logical-pixel side length on screen
  @override
  ConsumerState<AnimalView> createState() => _AnimalViewState();
}

class _AnimalViewState extends ConsumerState<AnimalView>
    with SingleTickerProviderStateMixin {
  late final AnimationController _ctrl;
  late final Animation<double> _scale;

  @override
  void initState() {
    super.initState();
    _ctrl = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 300),
    );
    _scale = TweenSequence<double>([
      TweenSequenceItem(tween: Tween(begin: 1.0, end: 1.15), weight: 40),
      TweenSequenceItem(tween: Tween(begin: 1.15, end: 1.0), weight: 60),
    ]).animate(_ctrl);
  }

  @override
  void dispose() {
    _ctrl.dispose();
    super.dispose();
  }

  Future<void> _onTap() async {
    final audio = ref.read(audioServiceProvider);
    final locale = ref.read(settingsProvider).locale;
    unawaited(audio.playSfx(widget.config.sfxKey));
    Future.delayed(const Duration(milliseconds: 150), () {
      if (!mounted) return;
      unawaited(audio.playVoice(widget.config.voiceKey, locale));
    });
    _ctrl.forward(from: 0);
  }

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: _onTap,
      behavior: HitTestBehavior.opaque,
      child: ScaleTransition(
        scale: _scale,
        child: Image.asset(
          widget.config.assetPath,
          width: widget.tileSize,
          height: widget.tileSize,
          filterQuality: FilterQuality.medium,
        ),
      ),
    );
  }
}
```

class ZooScreen extends ConsumerWidget {
  const ZooScreen({super.key});

  static const _aspectRatio = 3584 / 1184; // backdrop intrinsic

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    return Scaffold(
      backgroundColor: DesignTokens.cream,
      body: SafeArea(
        child: Stack(
          children: [
            LayoutBuilder(
              builder: (context, constraints) {
                final h = constraints.maxHeight;
                final w = h * _aspectRatio;
                final tileSize = h * 0.22; // ~120-150dp per animal
                return SingleChildScrollView(
                  scrollDirection: Axis.horizontal,
                  child: SizedBox(
                    width: w,
                    height: h,
                    child: Stack(
                      children: [
                        Positioned.fill(
                          child: Image.asset(
                            'assets/images/games/zoo/scene_zoo.png',
                            fit: BoxFit.cover,
                          ),
                        ),
                        for (final entry in zooAnimalConfigs.entries)
                          Positioned(
                            left: entry.value.positionX * w
                                - tileSize * entry.value.scale / 2,
                            top: entry.value.positionY * h
                                - tileSize * entry.value.scale / 2,
                            child: AnimalView(
                              config: entry.value,
                              tileSize: tileSize * entry.value.scale,
                            ),
                          ),
                      ],
                    ),
                  ),
                );
              },
            ),
            Positioned(
              top: DesignTokens.space2,
              left: DesignTokens.space2,
              child: _CircleOverlayButton(
                onTap: () => context.go('/'),
                child: const Icon(Icons.home_rounded, size: 32),
              ),
            ),
          ],
        ),
      ),
    );
  }
}
